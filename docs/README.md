# Documentation

This folder contains public-facing notes for users who want to understand the
extractor before running it on a large raw EEG dataset.

- [processing-methods.md](processing-methods.md): how CHB-MIT and EU records are
  parsed, converted, and matched to seizure intervals.
- [output-format.md](output-format.md): directory layout, `info.pkl` schema, and
  seizure interval conventions.

The documentation describes the behavior of this repository. It does not grant
access to the original datasets and does not replace the access, privacy, or
citation requirements of the dataset providers.
